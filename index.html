💾 학습 기록 백업 / 불러오기

완료 체크와 메모는 현재 브라우저의 로컬 저장소에 저장돼. 파일을 다른 브라우저에서 열거나 브라우저 데이터를 지우면 사라질 수 있으니 가끔 백업해 줘.

이 플래너는 인터넷 연결 없이도 열리지만, ChatGPT 앱에서 공부하려면 인터넷 연결이 필요해. 홈 화면에 추가하려면 브라우저에서 이 페이지를 열고 「홈 화면에 추가」를 사용해 봐. 단, 로컬 HTML 파일은 기기·브라우저에 따라 홈 화면 추가 기능이 제한될 수 있어.
